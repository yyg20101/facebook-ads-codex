# 产品需求

## 问题陈述

Meta 广告数据分散在多个业务和广告账户中，指标受币种、时区、归因窗口和数据回补影响。
分析人员需要可追溯的诊断和建议，同时广告写操作必须受权限、审批、预算、幂等和审计约束。

本项目使用 Codex 作为统一分析与编排入口，将实时数据和外部副作用交给确定性的
Cloudflare 控制平面。

## 主要用户

| 用户 | 主要目标 | 当前未决事实 |
| --- | --- | --- |
| 项目负责人 | 配置系统边界、审批高风险能力、查看全局状态 | `BQ-01`、`BQ-10`、`BQ-12` |
| 广告运营人员 | 分析表现、提出优化和提交变更 | 首批账户与业务模型 |
| 分析人员 | 获取统一口径的报告、对比和诊断 | KPI、转化事件和归因政策 |
| 只读查看者 | 查看授权范围内的数据与报告 | 实际成员和登录方式 |

具体角色能力以[角色与权限](roles-and-permissions.md)为准。

## 核心使用场景

1. 分析指定工作空间最近 7 天 ROAS 变化的主要驱动。
2. 找出花费增加但转化没有同步增长的 Ad Set。
3. 生成仅包含需要处理事项的每日简报。
4. 草拟预算或状态调整方案，但不直接执行。
5. 查询审批中的变更及其证据。
6. 在独立授权后执行已在网页批准的变更申请。
7. 当数据过期、口径缺失或同步失败时，优先报告数据问题。

## 成功结果

每个分析结果都能说明：

- Workspace 和 Meta Ad Account。
- 当前日期范围和对比范围。
- 币种、时区和归因口径。
- 数据更新时间、同步批次和稳定状态。
- 结论置信度。
- 建议和证据的对应关系。

只读 MVP 的完成标准、审批式 MVP 和有限自动化的定义见
[Gate 与证据](../planning/gates-and-evidence.md)。

## Phase 0 依赖

以下产品事实仍为 `UNRESOLVED`：

- 自有账户或客户账户业务模型：`BQ-01`。
- 首批广告账户数量和规模：`BQ-02`。
- 投放目标、主转化事件及现有转化数据：`BQ-03`–`BQ-05`。
- 币种、时区和归因口径：`BQ-06`、`BQ-07`。
- 回填和保留期：`BQ-08`、`BQ-09`。
- 审批用户、登录方式和主 Cloudflare 账户：`BQ-10`–`BQ-12`。

这些问题不阻塞文档基线，但会阻塞对应 Gate。
