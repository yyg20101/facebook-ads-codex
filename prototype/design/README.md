# 原型视觉基线

本目录保存 Product Discovery 阶段的界面概念和实现约束。概念图只用于视觉比对，
实际导航、文案、图表、表格、状态和交互必须由代码实现。

## 概念图

- `concepts/dashboard-desktop.png`：桌面总览，`1536 × 1024`
- `concepts/ad-builder-desktop.png`：广告创建与发布前检查，`1536 × 1024`
- `concepts/analytics-desktop.png`：数据下钻、诊断和待确认行动，`1536 × 1024`
- `concepts/testing-desktop.png`：素材测试、有效性检查和结论，`1536 × 1024`
- `concepts/dashboard-mobile.png`：移动端查看、审核和轻量操作，`852 × 1846`

## 设计系统

### 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--nav-950` | `#031b31` | 桌面侧栏和移动端顶栏 |
| `--nav-900` | `#06233d` | 侧栏悬停 |
| `--canvas` | `#f5f8fc` | 页面画布 |
| `--surface` | `#ffffff` | 主表面 |
| `--text-950` | `#101828` | 主要文字 |
| `--text-600` | `#586579` | 次要文字 |
| `--border` | `#dce4ef` | 分隔和控件边框 |
| `--blue-600` | `#075df5` | 主操作和选中状态 |
| `--blue-50` | `#eef6ff` | 信息背景 |
| `--green-600` | `#099268` | 正常和改善 |
| `--orange-600` | `#e77b16` | 警告 |
| `--red-600` | `#e13b3b` | 阻断和失败 |
| `--violet-600` | `#6d3fe0` | 对比指标 |

背景是冷调浅灰蓝和真正的白色，不使用米白、玻璃拟态或大面积装饰渐变。

### 字体与密度

- 字体：`Inter`、`Noto Sans SC`、`PingFang SC`、系统无衬线回退。
- 页面标题：桌面 `32px/1.2/700`，移动端 `28px/1.2/700`。
- 区域标题：`18px/1.35/700`。
- 正文与表单：`14px/1.55/400–500`。
- 控件与表格：`13px/1.4/500`，数值使用 tabular numbers。
- 页面间距采用 `4, 8, 12, 16, 20, 24, 32` 的节奏。
- 表面圆角 `10–12px`；输入框和按钮圆角 `6–8px`；边框 `1px`。

### 容器和组件

- 桌面：`202px` 固定侧栏、顶部可信提示、全局上下文栏、页面画布。
- 移动端：侧栏转换为底部导航；复杂创建流程给出桌面端提示，不压缩桌面表格。
- 优先使用开放区域、数据带、列表、表格、图表和右侧检查器。
- 只在需要表达独立对象时使用卡片，不使用默认 Bento 网格。
- 组件族：`AppShell`、`TrustBanner`、`ContextBar`、`Sidebar`、`MobileNav`、
  `MetricStrip`、`TrendChart`、`DataTable`、`TaskRail`、`StatusMark`、
  `BuilderTree`、`FormSection`、`PreflightPanel`、`DiagnosisInspector`、
  `TestPlanList`、`VariantComparison`、`ConclusionInspector`。

### 图标

图标统一使用 `lucide-react` 线框图标：

- `20px` 导航图标，`1.8px` 笔画。
- `16px` 控件图标，`1.7px` 笔画。
- 方向、展开、菜单和状态不得使用纯文本字符代替。
- 选中导航保持白色图标与文字；普通导航使用浅灰蓝。
- 错误、警告、成功分别使用红、橙、绿的圆形或方形状态容器。

## 首屏文案锁

桌面总览首屏只允许出现下列产品级文案及其数据值：

- `广告运营台`
- `原型数据 · 未连接 Meta · 不会执行外部写入`
- `星桥电商`、`DEMO-001`、`最近 7 天`、`Asia/Shanghai`
- `7 天点击 / 1 天浏览`、`更新于 08:42`、`Owner`
- `今日运营总览`、`创建广告`
- `消耗`、`购买`、`单次购买成本`、`ROAS`
- `投放趋势`、`需要处理`、`广告对象`、`素材表现`
- 一级导航中已确认的七个产品区域

实现不得增加聊天入口、实时连接声明、广告效果保证或自动写入暗示。

## 状态与动效

- 本地草稿、待确认、待审批、已发布、审核失败、数据不足和未执行建议必须可区分。
- 页面切换使用 `140–180ms` 淡入和轻微位移；数据更新使用短暂高亮。
- 所有动效遵循 `prefers-reduced-motion`。
- 任何“发布”“暂停”“调整”等操作只能更新原型本地状态，并继续显示无外部写入提示。
