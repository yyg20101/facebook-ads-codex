# 通用产品定义与 DG0

## 当前状态

```yaml
definition_status: DRAFT
dg0_status: PARTIAL
```

用户范围、角色、问题与价值假设、产品形态、3 个代表性场景、成功门槛和 MVP 边界均已

完成率和理解偏差仍未验证，因此 `DG0` 当前只能为 `PARTIAL`。

| PF-018 | 使用来源或商业授权不明的网络素材 | REJECTED | SC-01、SC-03 | `EVD-007`、`EVD-018` | 不得以生成或改编掩盖权利问题。 |
| PF-019 | 保证广告效果或保证通过 Meta 审核 | REJECTED | SC-01、SC-02 | `EVD-015`、`EVD-016`、`EVD-018` | 产品只能表达检查结果、证据和不确定性。 |
| PF-020 | 猜测关键配置、制造测试赢家或把相关性表述为因果 | REJECTED | SC-01–SC-03 | `EVD-015`–`EVD-018` | 信息不足时必须阻断、降级或返回不确定。 |

分类限定为：

- `MVP`：内部试点完成核心任务不可缺少。
- `LATER`：有价值但不阻塞内部试点。
- `REJECTED`：无证据、价值不足或不适合当前范围。

只有 `MVP` 项可以派生或恢复为 `FR-*`。没有证据的旧功能必须保持 `DRAFT`，不能默认进入
`LATER`。

## 内部试点非目标

- 外部客户、代理商、SaaS、多租户和商业化验证。
- production 部署、真实 Meta 数据接入或广告写操作。
- 以负责人决定或代表性场景推导市场规模、定价或外部购买意愿。
- 在产品形态确定前接受 Codex、Web、Cloudflare、MCP 或自动化架构。
