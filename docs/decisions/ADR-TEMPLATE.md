# ADR 模板

复制本文件后，将 front matter 替换为真实 `ADR-NNN`、状态、所有者和评审日期。

## 标题

`ADR-NNN：决策标题`

## 元数据

- 状态：`DRAFT`
- 决策日期：`YYYY-MM-DD`
- 决策者：`project_owner`
- 关联需求/任务：`TBD`
- 取代：`None`
- 被取代：`None`

## 背景

描述需要长期稳定决策的问题、约束、触发事件和证据。

## 决策驱动因素

- 驱动因素。

## 考虑的选项

说明每个可行选项、优点、缺点和风险。

## 决策

明确选择、适用边界和不包含的范围。`DRAFT` 时不得表述为已实施事实。

## 后果

分别记录收益、代价、限制和后续工作。

## 安全、租户和数据影响

- 认证与授权。
- 租户隔离。
- Secret 与敏感数据。
- 数据、migration、审计和恢复。
- 新增攻击面。

## 接口与 Gate 影响

- 受影响需求。
- MCP/HTTP 接口。
- 阶段任务和 Gate。
- 测试与证据。

## 推进与回滚

说明实施顺序、验证、回滚或前向修复。

## 文档变更

列出需要同步更新的需求、技术、规范、路线图和变更日志。
