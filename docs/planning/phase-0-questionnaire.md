2. 每项答案记录负责人、证据和确认日期。
3. 未确定值使用 `UNRESOLVED`，不得猜测默认值。
4. 所有阻塞问题关闭并满足证据要求后，才能评估 G0。
5. Gate 通过时记录确认者和证据，不只填写布尔值。
6. 在获得单独授权前，只收集事实；不得访问 Meta/Cloudflare、创建资源或处理密钥。

## 广告账户上下文原则

`BQ-03`–`BQ-08` 涉及的投放目标、转化事件、主 KPI、币种、时区、归因口径和可用
历史范围，不是项目级固定配置。获得单独的 Meta 只读访问授权后，产品 MUST 从当前
广告账户、Campaign、Ad Set、Ad 及查询返回数据中动态解析，并遵守以下规则：

- 每项分析必须保留广告账户、广告对象、日期范围、币种、时区、归因口径和数据截至时间。
- 主 KPI 必须依据当前广告对象的实际投放目标、转化事件和可用指标选择，不得硬编码一个
  适用于所有账户的指标。
- 只有上下文兼容的数据才能聚合或比较；不同币种、时区、归因口径或转化事件不得静默混合。
- 账户或查询未返回、存在冲突或无法识别的值必须标记为 `UNKNOWN` 或 `UNAVAILABLE`，
  不得要求负责人猜测，也不得由系统补写默认值。
- 历史分析范围以用户请求和该账户实际可用数据的交集为准，并显示实际覆盖范围。

本原则是产品与数据口径决策，不构成当前 Meta 账户访问授权。
