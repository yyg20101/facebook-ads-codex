# Meta 广告全流程运营平台产品定义与 DG0

## 当前状态

```yaml
definition_status: DRAFT
dg0_status: PARTIAL
```

产品负责人已确认最终产品是覆盖素材、广告创建与发布、投放管理、数据分析和持续优化的
通用 Meta 广告 Web 运营平台。前期 AI 助手位于独立 Codex 会话，通过项目上下文、
信息文档和 Skills 工作，不要求在 Web 内置聊天入口。

旧三形态静态故事板没有表达该产品形态，已被负责人拒绝且不产生 Gate 证据。正确形态
的本地 Web 交互原型与 Codex 场景包已完成技术验收，但尚未由负责人完成产品走查，
因此 `DG0` 保持 `PARTIAL`。

## 产品分层

### Web 运营平台

Web 是产品主体和业务事实界面，MUST 承载：

- 素材、Campaign、Ad Set、Ad、诊断、测试和变更等结构化对象。
- 数据范围、新鲜度、状态、权限、风险、审批和审计。
- 从广告准备到投放后优化的连续导航与跨对象关系。
- 在能力尚未授权或实现时清晰禁用并解释对应操作。

### Codex AI 助手

前期 Codex 是独立辅助界面，MUST：

- 读取当前任务允许使用的项目文档、上下文和 Skills。
- 辅助素材构思、广告配置、指标解释、异常诊断、优化建议和报告整理。
- 在缺少实时数据或受控工具时明确限制，MUST NOT 假装已读取或修改 Meta。
- 将重要输出结构化，便于后续保存到 Web 对象或受控工作流。

未来是否增加 Web 内置 AI 入口必须另行提供价值证据，不是当前 MVP 前提。

- 在 Web 中重复实现 Codex 对话能力。
- 以负责人决定或脱敏原型推导真实效率、诊断准确率或广告效果。
- 以当前只读授权缩小最终产品的全流程目标。
